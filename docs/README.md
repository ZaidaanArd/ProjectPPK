# Dokumentasi Sthana Kampus

Mulai dari [panduan pengguna](./USER-GUIDE.md) untuk memakai aplikasi, atau [runbook](./OPERATIONS.md) untuk menjalankan dan merilisnya. Dokumen ini mengikuti implementasi repository; hasil uji manual dan persetujuan tidak otomatis dianggap lulus hanya karena fitur sudah ada.

| Dokumen                                            | Kegunaan                                                         |
| -------------------------------------------------- | ---------------------------------------------------------------- |
| [User Guide / User Manual](./USER-GUIDE.md)        | Alur pengunjung, pengguna, petugas, dan admin                    |
| [UAT / Acceptance Report](./UAT.md)                | Skenario penerimaan US-01–US-17 dan tempat mencatat hasil        |
| [Test Report](./TEST-REPORT.md)                    | Hasil pengujian yang benar-benar dijalankan dan gap yang tersisa |
| [Deployment / Operations Runbook](./OPERATIONS.md) | Setup, rilis, health check, insiden, dan rollback                |
| [Release Notes / Changelog](./CHANGELOG.md)        | Ringkasan perubahan berdasarkan riwayat Git                      |
| [Security & Privacy Notes](./SECURITY-PRIVACY.md)  | Kontrol akses, data yang disimpan, dan batasan yang diketahui    |
| [Architecture Decision Records](./adr/README.md)   | Alasan keputusan teknis utama                                    |
| [Engineering Case Study](./CASE-STUDY.md)          | Masalah, rancangan, implementasi, dan hasil yang terukur         |

Dokumen teknis yang sudah ada: [requirements](./REQUIREMENTS.md), [arsitektur](./ARCHITECTURE.md), [data dan API](./DATA-AND-API.md), [SEO](./SEO.md), dan [pembagian tim](./TEAM-WORK.md). [Roadmap](./ROADMAP.md) adalah catatan perencanaan historis; rujuk kode dan ADR untuk arsitektur saat ini.
